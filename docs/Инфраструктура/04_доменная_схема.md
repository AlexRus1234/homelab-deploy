# Доменная схема

Локальные доменные зоны `*.internal` обслуживаются DNS-сервером SHLZ00. Каждая зона привязана к узлу `YADRXX` и резолвится на IP локального инстанса Caddy (Reverse Proxy) этого узла.

## 1. Структура зон

| Зона | IP Caddy (LXC) | Узел |
| :--- | :--- | :--- |
| `*.yadr00.internal` | `172.20.5.3` | YADR00 |
| `*.yadr01.internal` | `172.20.6.2` | YADR01 |

> Каждая ВМ `YADRXX` имеет собственный инстанс Caddy в отдельном LXC. Caddy терминирует TLS (сертификаты выдаёт Step-CA через ACME) и проксирует запросы на целевые сервисы (ВМ/LXC/управляющие интерфейсы).

## 2. Известные записи

### yadr00 (`*.yadr00.internal` → Caddy `172.20.5.3`)

| Домен | Целевой бэкенд | Примечание |
| :--- | :--- | :--- |
| `proxmox.yadr00.internal` | `https://172.20.5.1:8006` | Proxmox VE (yadr00) |
| `git.yadr00.internal` | `172.20.5.2:3000` | Forgejo (Git-сервер, реестр пакетов) |
| `authentic.yadr00.internal` | `172.20.5.4:9000` | Сервис аутентификации |
| `alpine-vaultwarden.yadr00.internal` | `https://172.20.5.6:8000` | Vaultwarden |
| `memos.yadr00.internal` | `172.20.5.17:10004` | Memos (ВМ obshaga). Исключение: проброс напрямую на ВМ |

### yadr01 (`*.yadr01.internal` → Caddy `172.20.6.2`)

| Домен | Целевой бэкенд | Примечание |
| :--- | :--- | :--- |
| `proxmox.yadr01.internal` | `https://172.20.6.1:8006` | Proxmox VE (yadr01) |
| `pbs.yadr01.internal` | `https://172.20.6.3:8007` | Proxmox Backup Server |
| `sftpgo.yadr01.internal` | `172.20.6.8:8080` | SFTP/FTP-сервер |
| `matrix.yadr01.internal` | — | Matrix-сервер (yadr01) |

> Часть адресов на каждом узле вынесена в отдельные файлы `/etc/caddy/caddy_conf/*.caddy` внутри LXC (подгружаются через `import`). Полный список записей будет дополнен после выгрузки актуальной зоны с SHLZ00. В будущем планируется переход Caddy на управление через API (без редактирования файлов).

## 3. TLS (Step-CA / ACME)

Сертификаты для доменов `*.yadrXX.internal` выдаёт Step-CA, запущенный на SHLZ00. Caddy получает их автоматически по ACME-протоколу:

*   **Directory:** `https://172.20.0.1:9000/acme/acme/directory`
*   **Корневой сертификат:** `http://172.20.0.1:9000/roots.pem` (должен быть доверенным на узле Caddy — `/etc/caddy/root_ca.crt`).
*   **ACME-слушатель:** Caddy слушает `:80` для прохождения `/.well-known/acme-challenge`.

## 4. Конфигурация Caddy

Эталонные `Caddyfile` хранятся в репозитории:
*   [`Caddyfile.yadr00.template`](../../system-templates/caddy/Caddyfile.yadr00.template) — инстанс yadr00 (Proxmox, Vaultwarden, Authentic, Forgejo).
*   [`Caddyfile.yadr01.template`](../../system-templates/caddy/Caddyfile.yadr01.template) — инстанс yadr01 (layer4 TCP-прокси, Proxmox, PBS, SFTPGo).

Оба включают сниппет `my_tls` (ACME через Step-CA), `import /etc/caddy/caddy_conf/*.caddy` (подгрузка дополнительных файлов внутри LXC) и слушатель `:80` для ACME-challenge.

> В будущем планируется переход на управление Caddy через API (отказ от файлового редактирования).
