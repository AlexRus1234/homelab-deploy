# Доменная схема

Локальные доменные зоны `*.internal` обслуживаются DNS-сервером SHLZ00. Каждая зона привязана к узлу `YADRXX` и резолвится на IP локального инстанса Caddy (Reverse Proxy) этого узла.

## 1. Структура зон

| Зона | IP Caddy (LXC) | Узел |
| :--- | :--- | :--- |
| `*.yadr00.internal` | `172.20.5.3` | YADR00 |
| `*.yadr01.internal` | `172.20.6.2` | YADR01 |

> Каждая ВМ `YADRXX` имеет собственный инстанс Caddy в отдельном LXC. Caddy терминирует TLS (сертификаты выдаёт Step-CA через ACME) и проксирует запросы на целевые сервисы (ВМ/LXC/управляющие интерфейсы).

## 2. Известные записи

| Домен | Целевой бэкенд | Примечание |
| :--- | :--- | :--- |
| `proxmox.yadr00.internal` | Proxmox VE (yadr00) | Web UI управления гипервизором |
| `proxmox.yadr01.internal` | `https://172.20.6.1:8006` | Web UI Proxmox VE (yadr01) |
| `pbs.yadr01.internal` | `https://172.20.6.3:8007` | Proxmox Backup Server (yadr01) |
| `authentic.yadr00.internal` | — | Сервис аутентификации (yadr00) |
| `git.yadr00.internal` | Forgejo | Git-сервер, реестр пакетов |
| `sftpgo.yadr01.internal` | `172.20.6.8:8080` | SFTP/FTP-сервер |
| `matrix.yadr01.internal` | — | Matrix-сервер (yadr01) |
| `memos.yadr00.internal` | `172.20.5.17:10004` | Memos (ВМ obshaga). Исключение: проброс идёт напрямую на ВМ, а не на стандартный бэкенд |

## 3. TLS (Step-CA / ACME)

Сертификаты для доменов `*.yadrXX.internal` выдаёт Step-CA, запущенный на SHLZ00. Caddy получает их автоматически по ACME-протоколу:

*   **Directory:** `https://172.20.0.1:9000/acme/acme/directory`
*   **Корневой сертификат:** `http://172.20.0.1:9000/roots.pem` (должен быть доверенным на узле Caddy — `/etc/caddy/root_ca.crt`).
*   **ACME-слушатель:** Caddy слушает `:80` для прохождения `/.well-known/acme-challenge`.

## 4. Конфигурация Caddy

Эталонный `Caddyfile` (инстанс yadr01) хранится в репозитории: [`system-templates/caddy/Caddyfile.template`](../../system-templates/caddy/Caddyfile.template). Включает:

*   Блок `layer4` — TCP-прокси (`:65022` → `172.20.6.8:2022`, альтернативный порт SFTP).
*   Сниппет `my_tls` — параметры ACME-выпуска сертификатов через Step-CA.
*   Правила `reverse_proxy` для Proxmox, PBS, SFTPGo.
*   `import /etc/caddy/caddy_conf/*.caddy` — подгрузка дополнительных файлов конфигурации внутри LXC.

> Конфигурация Caddy для yadr00 хранится в соответствующем LXC и в данный момент в репозиторий не выкладывается.
