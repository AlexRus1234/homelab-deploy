# Доменные имена — сводная таблица IP:port

Локальные доменные зоны `*.internal` обслуживаются DNS-сервером SHLZ00 и резолвятся на IP локального инстанса Caddy (Reverse Proxy) соответствующего узла. Caddy терминирует TLS (сертификаты Step-CA через ACME) и проксирует запросы на целевые бэкенды.

## 3. Метод управления

| Метка | Описание |
| :--- | :--- |
| **Caddyfile** | Запись прописана в эталонном шаблоне репозитория (`system-templates/caddy/Caddyfile.*.template`) |
| **import** | Запись подгружается через `import /etc/caddy/caddy_conf/*.caddy` внутри LXC |
| **API** | Запись добавлена через Caddy Admin API (`:2019`); не отражена в шаблонах репозитория |

## 4. Схема проброса (Reverse Proxy)

```
Клиент → DNS (SHLZ00) → Caddy LXC → Бэкенд (ВМ/LXC)
         резолв           терминирует     сервис на целевом
         домена в          TLS (ACME)     IP:Port
         IP Caddy
```
