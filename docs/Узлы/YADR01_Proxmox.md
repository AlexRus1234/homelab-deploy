# YADR01 — Гипервизор Proxmox (второй сервер)

> **Узел:** `YADR01`
> **Роль:** Второй вычислительный узел — тяжёлые/инфраструктурные сервисы, хранилища и лента.
> **ОС:** Proxmox VE
> **Сеть:** две — `vmbr0` (основная, управление `172.20.6.1:8006`) + `vmbr1` (прямой линк 2.5G до SKLD00)

---

## 1. Аппаратная часть

| Компонент | Значение |
| :--- | :--- |
| **CPU** | AMD Ryzen 7 5800HS (8 ядер) |
| **RAM** | 64 ГБ DDR4 |
| **Диски** | NVMe + SATA SSD |
| **Сеть** | 2× LAN (один порт — `vmbr0`, второй — прямой линк `vmbr1` 2.5G) |

---

## 2. Сеть

| Мост | Адрес | Назначение |
| :--- | :--- | :--- |
| `vmbr0` | `172.20.6.1` | Основная сеть (управление, сервисы) |
| `vmbr1` | `172.21.6.250/24` | Прямой линк до SKLD00 (`.249`) — БД/S3/SMB мимо коммутатора |

План адресации линка `172.21.6.0/24` — в [Архитектура и сеть](../Инфраструктура/01_архитектура_и_сеть.md). SMB-шара NAS монтируется по линку (`//172.21.6.249/Share`), см. [08 — Proxmox: бекап PBS](../Настройка/08_Proxmox_бекап_PBS.md).

> Узлы **не кластеризованы** (осознанно — кворум/сплит-брейн для двух нод не имеет смысла).

---

---

## 4. Специфика

- Гости с тяжёлым дисковым/сетевым трафиком (panelka, sftpgo) подключены вторым интерфейсом к `vmbr1` — данные ходят в NAS напрямую.
- Бэкап хоста `/etc` на PBS — скриптом `/root/backup-host.sh` (namespace `yadr01`, см. [08 — Proxmox: бекап PBS](../Настройка/08_Proxmox_бекап_PBS.md)).
- Джобы бэкапа ВМ/LXC из PVE — nightly snapshot на PBS (см. [15 — PBS-сервер](../Настройка/15_PBS_сервер.md)).
