# YADR00 — Гипервизор Proxmox (первый сервер)

> **Узел:** `YADR00`
> **Роль:** Первый вычислительный узел — легковесные пользовательские сервисы и SSO-инфраструктура.
> **ОС:** Proxmox VE
> **Сеть:** `vmbr0` — основная сеть (управление `172.20.5.1:8006`, домен `proxmox.yadr00.internal`)

---

## 1. Аппаратная часть

| Компонент | Значение |
| :--- | :--- |
| **Платформа** | Мини-ПК IPC-3100 (Intel) |
| **CPU** | Intel N100 |
| **RAM** | 32 ГБ DDR4 (апгрейд с фабричной) |
| **Диски** | 2.5" SSD + NVMe (система и локальные хранилища) |
| **Сеть** | 1× 1GbE |
| **Потребление** | ~10 Вт простой / ~20 Вт нагрузка |

---

## 2. Сеть

| Мост | Подсеть | Назначение |
| :--- | :--- | :--- |
| `vmbr0` | `172.20.5.x` | Основная сеть (управление, сервисы) |

Прямого линка (`vmbr1`) до SKLD00 **нет** — SMB-шара NAS монтируется через основную сеть (`172.20.50.1`), см. [08 — Proxmox: бекап PBS](../Настройка/08_Proxmox_бекап_PBS.md).

---

## 3. Гостевой парк (LXC + ВМ)

| Гость | Тип | IP | Назначение |
| :--- | :--- | :--- | :--- |
| Caddy | LXC | `172.20.5.3` | Reverse Proxy узла (Caddyfile-шаблон `Caddyfile.yadr00.template`) |
| Forgejo | LXC (CT 108) | `172.20.5.2` | Git-сервер + реестр пакетов ([09 — Forgejo](../Настройка/09_Forgejo_Git_CI.md)) |
| Authentik | ВМ (VM 102) | `172.20.5.4` | SSO-провайдер ([11 — Authentik](../Настройка/11_Authentik_SSO.md)) |
| Vaultwarden | LXC | `172.20.5.6` | Менеджер паролей (из эп. 6; **планируется переделка**) |
| `obshaga` | ВМ (VM 115) | `172.20.5.17` | Пользовательские сервисы (Dashy, LinkStack, Memos, Mortis) — GitOps |

> Шаблон базовой ВМ (Arch, `Base`/VM 102-клоны) хранится на этом узле; из него разворачиваются ВМ `obshaga` и Authentik (а также клон для runner — но сам `gitrunner` живёт на [YADR01](YADR01_Proxmox.md)).

---

## 4. Специфика

- Гости, не вписывающиеся в модель Rootless Podman (Caddy, Forgejo, Vaultwarden), живут в LXC.
- ВМ используют стандарт: порты сервисов `10000+`, запуск от пользователя `app-runner` (см. [Спецификация ВМ](../Инфраструктура/02_спецификация_вм.md) и [GitOps](../Инфраструктура/03_gitops_агент.md)).
- Бэкап хоста `/etc` на PBS — скриптом `/root/backup-host.sh` (namespace `yadr00`, см. [08 — Proxmox: бекап PBS](../Настройка/08_Proxmox_бекап_PBS.md)).
