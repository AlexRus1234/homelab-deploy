# 04 — Роутер: Базовая настройка сети

> Узел: **SHLZ00** (Arch Linux). Превращение мини-ПК в маршрутизатор.
> Контекст: [SHLZ00 — Роутер](../Узлы/SHLZ00_роутер.md)

## Топология интерфейсов

| Интерфейс | Роль | Подсеть |
| :--- | :--- | :--- |
| `enp6s0` | WAN (Интернет) | DHCP от провайдера |
| `enp5s0` | LAN (Основная) | `172.20.0.1/16` |
| `enp3s0` | IoT (Вещи) | `172.22.0.1/16` |
| `enp1s0` | Rescue (Аварийный) | `192.168.99.1/24` |

---

## 1. Подготовка системы

```bash
# Необходимый софт
pacman -Syu systemd dnsmasq nftables ethtool chrony neovim

# Удалить дефолтные конфиги сети, чтобы не мешали
rm /etc/systemd/network/20-ethernet.network 2> /dev/null
rm /etc/systemd/network/20-wlan.network 2> /dev/null

# Отключить конфликтующие службы
systemctl disable --now NetworkManager dhcpcd systemd-resolved
```

---

## 2. Настройка L2/L3 (systemd-networkd)

4 файла в `/etc/systemd/network/`.

**`20-wan.network`**
```ini
[Match]
Name=enp6s0

[Link]
MACAddress=AA:BB:CC:DD:EE:FF   # клонируем MAC старого роутера

[Network]
DHCP=ipv4
IPMasquerade=ipv4
```

**`30-lan.network`**
```ini
[Match]
Name=enp5s0

[Network]
Address=172.20.0.1/16
DHCPServer=no
ConfigureWithoutCarrier=yes   # вешать IP даже без кабеля
```

**`40-iot.network`**
```ini
[Match]
Name=enp3s0

[Network]
Address=172.22.0.1/16
DHCPServer=no
ConfigureWithoutCarrier=yes
```

**`10-rescue.network`**
```ini
[Match]
Name=enp1s0

[Network]
Address=192.168.99.1/24   # статика для прямого подключения
DHCP=ipv4                 # клиент для спасения в другой сети
```

---

## 3. Маршрутизация (ядро)

`/etc/sysctl.d/99-router.conf`:
```ini
net.ipv4.ip_forward = 1
```
Применить без перезагрузки: `sysctl --system`

---

## 4. DNS и DHCP (dnsmasq)

### Устранение конфликта 53 порта
```bash
rm /etc/resolv.conf
echo "nameserver 8.8.8.8" > /etc/resolv.conf
```

### `/etc/dnsmasq.conf`
```ini
# Не слушать на порту провайдера
except-interface=enp6s0
interface=enp5s0
interface=enp3s0
interface=enp1s0

domain-needed
bogus-priv
no-resolv
server=8.8.8.8
server=1.1.1.1

# LAN (172.20.x.x)
dhcp-range=interface:enp5s0,172.20.255.10,172.20.255.250,255.255.0.0,12h
domain=lan,172.20.0.0/16
expand-hosts

# IoT (172.22.x.x)
dhcp-range=interface:enp3s0,172.22.0.10,172.22.0.250,255.255.0.0,12h

# Rescue (192.168.99.x)
dhcp-range=interface:enp1s0,192.168.99.10,192.168.99.20,255.255.255.0,1h
```

## 5. Firewall и NAT (nftables)

`/etc/nftables.conf`:
```nft
flush ruleset

table ip nat {
    chain postrouting {
        type nat hook postrouting priority 100; policy accept;
        # NAT только на WAN
        oifname "enp6s0" masquerade
    }
}

table inet filter {
    chain input {
        type filter hook input priority 0; policy drop;

        ct state established,related accept
        iifname "lo" accept
        ip protocol icmp accept

        # Доступ к роутеру (SSH/DNS) ТОЛЬКО изнутри — WAN здесь НЕТ
        iifname { "enp5s0", "enp3s0", "enp1s0" } accept
    }
    chain forward {
        type filter hook forward priority 0; policy accept;
    }
}
```

---

## 6. Финализация и запуск

```bash
systemctl enable --now systemd-networkd
systemctl enable --now nftables
systemctl enable --now dnsmasq
systemctl enable --now chronyd
```

**Проверка:**
1. `ip a` — все интерфейсы имеют IP (даже без кабеля).
2. `networkctl status` — все интерфейсы `configured`.
3. Подключить ПК в LAN (`enp5s0`) → получить IP `172.20.255.xx` → интернет работает.
