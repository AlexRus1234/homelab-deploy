# vps/site/link — статичная страница ссылок

Замена LinkStack на публичном домене `link.alexrus1234.ru`. Страницу целиком отдаёт **Caddy на VPS** (`file_server`), никакого приложения и БД: правится текстовый файл — меняется страница.

```
vps/site/link/
├── index.html   вся страница: разметка, стили и рендер — в одном файле, без зависимостей и сборки
├── links.json   список и разметка ресурсов — единственный файл, который нужно править руками
└── README.md    этот файл
```

## Как это работает

`index.html` при загрузке запрашивает `links.json` (`fetch`, `cache: 'no-store'`) и строит страницу из него: секции = группы, карточки = ссылки. Ничего не собирается, внешних CDN нет — только системный шрифт, никаких иконок и эмодзи.

Требование: страница должна отдаваться по **http(s) с того же хоста**, что и `links.json` (иначе `fetch` заблокирует). Открывать локально двойным щелчком (`file://`) бессмысленно — вместо карточек будет сообщение об ошибке.

## Раскладка

**Одна группа — одна строка карточек:** число колонок в группе равно числу ссылок в ней (`--cols` выставляется рендером). На узких экранах (≤1040px) сетка переносится как обычно — иначе карточки сжались бы в нечитаемые столбцы.

## Формат links.json

```json
{
  "site": {
    "title": "AlexRus1234"             // крупный заголовок страницы
  },
  "groups": [
    {
      "name": "Видео",                  // заголовок группы (он же участвует в фильтре)
      "note": "четыре площадки",        // необязательно: подпись под заголовком
      "links": [
        {
          "title": "YouTube",           // имя карточки
          "url": "https://youtube.com/...",
          "description": "Основной канал с выпусками",
          "tags": ["видео"],            // необязательно: плашки (тоже участвуют в фильтре)
          "copy": false                 // необязательно: true — карточка не открывается, клик копирует ссылку
        }
      ]
    }
  ]
}
```

Добавить ссылку = добавить объект в массив `links`. Порядок карточек = порядок в файле, число колонок в строке подстроится само. В фильтр попадают `title`, `url`, `description`, `tags` и имя группы.

**Внизу каждой карточки стоит та же ссылка моноширинным шрифтом** — клик по ней копирует адрес, а не открывает его; на карточке с `"copy": true` копирует и клик по самой карточке. Если браузер не пускает к буферу обмена (страница отдана по `http`, а не `https`), текст просто выделяется — остаётся нажать `Ctrl+C`.

Оформление намеренно сухое: плоские карточки с тонкой рамкой, без градиентов, размытия, теней и анимаций появления; светлая тема включается настройкой системы.

## Установка на VPS (делается на этапе переноса, сейчас не выполнено)

1. Скопировать `index.html` и `links.json` на VPS, например в `/srv/link/`.
2. В `/etc/caddy/Caddyfile` заменить блок LinkStack на раздачу статики:

```
link.alexrus1234.ru {
    root * /srv/link
    file_server
    encode zstd gzip
}
```

3. `sudo caddy validate --config /etc/caddy/Caddyfile && sudo systemctl reload caddy`.

Проверка после переноса: страница открывается по `https://link.alexrus1234.ru`, внизу видно счётчик ссылок, `/admin` больше не существует ни как 403, ни как редирект.
