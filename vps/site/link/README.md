# vps/site/link — статичная страница ссылок

Замена LinkStack на публичном домене `link.alexrus1234.ru`. Страницу целиком отдаёт **Caddy на VPS** (`file_server`), никакого приложения и БД: правится текстовый файл — меняется страница.

```
vps/site/link/
├── index.html   вся страница: разметка, стили и рендер — в одном файле, без зависимостей и сборки
├── links.json   список и разметка ресурсов — единственный файл, который нужно править руками
└── README.md    этот файл
```

## Как это работает

`index.html` при загрузке запрашивает `links.json` (`fetch`, `cache: 'no-store'`) и строит страницу из него: секции = группы, карточки = ссылки. Ничего не собирается, внешних CDN нет — только системные шрифты и эмодзи.

Требование: страница должна отдаваться по **http(s) с того же хоста**, что и `links.json` (иначе `fetch` заблокирует). Открывать локально двойным щелчком (`file://`) бессмысленно — вместо карточек будет сообщение об ошибке.

## Формат links.json

```json
{
  "site": {
    "title": "AlexRus1234",              // крупный заголовок
    "subtitle": "Домашний ЦОД: ...",     // строка под заголовком
    "avatar": "🚀",                      // необязательно: эмодзи вместо иконки слева (по умолчанию 🚀)
    "meta": "",                          // необязательно: HTML справа в шапке
    "footer": "Статика, Caddy · ..."     // необязательно: нижний колонтитул
  },
  "groups": [
    {
      "name": "Публичные сервисы",       // заголовок группы
      "note": "доступны из интернета",   // необязательно: подпись под заголовком
      "links": [
        {
          "title": "Element",            // имя карточки
          "url": "https://element.alexrus1234.ru",
          "icon": "💬",                  // необязательно: эмодзи карточки
          "description": "Matrix-клиент",
          "tags": ["matrix", "чат"]      // необязательно: плашки (участвуют в фильтре)
        }
      ]
    }
  ]
}
```

Добавить ссылку = добавить объект в массив `links`. Порядок карточек = порядок в файле. Поле `tags` и `description` попадают в строку поиска вместе с `title` и `url`.

Что уже есть на странице: эффекты — анимированный градиентный фон, всплытие карточек с задержкой по индексу, подъём и подсветка карточки под курсором, копирование ссылки кнопкой, фильтр по имени/описанию/тегу. Всё уважает `prefers-reduced-motion` и светлую тему системы.

## Установка на VPS (делается на этапе переноса, сейчас не выполнено)

1. Скопировать `index.html` и `links.json` на VPS, например в `/srv/link/`.
2. В `/etc/caddy/Caddyfile` заменить блок LinkStack на раздачу статики:

```
link.alexrus1234.ru {
    root * /srv/link
    file_server
    encode zstd gzip
}
```

3. `sudo caddy validate --config /etc/caddy/Caddyfile && sudo systemctl reload caddy`.

Проверка после переноса: страница открывается по `https://link.alexrus1234.ru`, внизу видно счётчик ссылок, `/admin` больше не существует ни как 403, ни как редирект.
