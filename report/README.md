# report/

Каталог для служебных отчётов, генерируемых в процессе эксплуатации инфраструктуры:

*   логи/выводы работы `sync-state.sh` при ручном запуске (если включён режим логирования);
*   отчёты аудита состояния ВМ и контейнеров;
*   протоколы разовых операций (массовые перезапуски, миграции, восстановление из бэкапа).

Файлы в этом каталоге не являются частью конфигурации GitOps и не используются скриптами синхронизации автоматически. Содержимое добавляется вручную по мере необходимости.
